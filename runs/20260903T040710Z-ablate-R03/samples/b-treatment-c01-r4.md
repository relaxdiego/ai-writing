The session cache had its TTL hardcoded twice over: `src/cache/session.py` set `session_ttl = 3600` on the class while `src/config/defaults.py` declared `SESSION_TTL_SECONDS = 900`, so the configured value was never the one the expiry check in `get()` actually used. I pointed the class attribute at the constant, which changes the effective TTL from an hour to fifteen minutes and makes `defaults.py` the single place that value lives. The name resolves without a new import in either file, since the test run would otherwise have failed at import time rather than on an assertion.

That change broke `test_expiry_boundary`, which asserted the literal `3600`; it was pinning the duplicate rather than the behaviour, so I rewrote it against `SESSION_TTL_SECONDS` too. The full file now passes, eight tests.
